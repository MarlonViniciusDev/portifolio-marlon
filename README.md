## Como executar

### Opção 1 — abrir diretamente
Abra `index.html` no navegador.

### Opção 2 — VS Code + Live Server
1. Abra a pasta no VS Code.
2. Abra `index.html`.
3. Clique com o botão direito no arquivo.
4. Selecione **Open with Live Server**.

## Antes de publicar

No `index.html`, substitua os placeholders de:
- e-mail
- WhatsApp
- GitHub
- Instagram (se quiser)
- link do projeto LêLiDan Joias
- links de código no GitHub, quando existirem

O formulário atualmente valida os campos, mas não envia mensagens para um servidor. Para envio real, conecte-o posteriormente a um backend ou serviço de formulários.

Não há framework ou Bootstrap neste projeto.
