## 🚀 Funcionalidades

### Navegação

Navegação por seções com destaque automático no menu conforme o usuário percorre a página.

### Menu responsivo

Em telas menores, o menu principal é transformado em um menu mobile com abertura e fechamento.

### Animações

O site possui animações e efeitos de revelação durante a navegação.

### Formulário de contato

O formulário possui validação em JavaScript para:

* Nome
* E-mail
* Mensagem

Após a validação, o formulário utiliza o **Formspree** para realizar o envio das mensagens.
